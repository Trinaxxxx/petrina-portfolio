# Petrina Kinzel — Portfolio

Source for the personal portfolio of **Petrina Kinzel**, Technical Environment
Artist — environment art, tech-art, and the in-house tools built along the way.

**🔗 Live site:** https://petrina-portfolio.vercel.app

## Where the project lives

The production site is the Next.js app in **[`portfolio/`](portfolio/)** — see
its [README](portfolio/README.md) for the stack, setup, and run steps.

```bash
cd portfolio
npm install
npm run dev
```

## Built with

Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · Motion · GSAP · deployed on Vercel.
